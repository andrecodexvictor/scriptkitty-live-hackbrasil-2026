# ScriptKitty Live — Product Identity & Copy Guidelines

## Product Positioning
**ScriptKitty Live** (with its defensive security agent **PatchCat** and deterministic graph engine **ChainBreak**) is a deterministic permission, data-flow, and security verification console for engineering teams building software and MCP tool integrations.

- **Audience:** Staff engineers, AppSec reviewers, security architects, and developers evaluating access boundaries and release readiness before merge.
- **Physical Scene:** A focused security engineering workbench — deep graphite obsidian surfaces (`#0C121A` / `#111C28` / `#162330` in OKLCH) paired with crisp ice-blue (`#79B7F3`), emerald-green (`#64CDB1`), and restrained telemetry violet (`#A594F9`), plus a high-legibility daylight toggle (`data-theme="light"`).
- **Register:** Product + Restrained Technical Editorial (`apps/ui` landing + live interactive console, `vercel-app` public showcase).

## Capabilities & Naming Discipline
1. **Product Name:** **ScriptKitty Live**
2. **Agent Name:** **PatchCat**
3. **Primary Capability:** **ChainBreak** (deterministic policy-graph reachability and counterfactual minimal-edge remediation)
4. **Core Capabilities:**
   - **Continuous Security Audit:** Reachability verification over synthetic policy graphs and isolated AppSec lab targets (`CWE-89`, `CWE-78`, `CWE-639`).
   - **Verified Remediation:** Minimal-change counterfactual diff synthesis (`1 -> 0` forbidden paths while preserving `3/3` legitimate operations) with mandatory human approval.
   - **Agent & MCP Security:** Fail-closed loopback MCP Streamable HTTP (`127.0.0.1`), runtime boundary enforcement, Tri-Party Separation of Duties (`Discoverer != Verifier != Authorizer`), and RFC 8785 cryptographic custody proofs.

## Copy & Domain Discipline
- Top-level navigation, hero copy, landing sections, and primary panel headings NEVER expose internal adapter, framework, or plumbing names (`Invokta`, `JEV`, `JEV-as-a-Judge`, `Harness²`, `Mantis`, `Company Brain`, `Factory`, `TypeSafe`).
- Users see clear product concepts:
  - **Access Reachability Graph** (`ChainBreak`)
  - **Human Risk Review** (human-gated risk triage & evidence sufficiency checks)
  - **Counterfactual Fix Spec** (1-line edge removal preview)
  - **Release Gate & Custody Proof** (3-party independent sign-off, Merkle root, delivery eligibility)
  - **Registered MCP Tools** (live tool inventory synced from the connected MCP server)
- Technical audit invariants (`PATH_VALIDATED`, `NEVER EXPLOIT_CONFIRMED`, `PENDING_REVIEW`, `MOCK`, `NOT_CONFIGURED`, `NO_RESTRICTED_DATA_EXTERNAL_TRANSFER`, `E_SOD_SELF_CERTIFICATION`, `mergeAllowed: false`, `deployAllowed: false`, `requiresHumanApproval: true`, `autoApplyAllowed: false`, SHA-256 digests) stay transparently inspectable inside collapsible `<details class="tech-receipt">` cryptographic receipts and honest `IMPLEMENTED / PARTIAL / PLANNED` status tables.
- Laboratory disclosures remain explicit: synthetic data only, `productionTested: false`, zero autonomous merge/deploy, zero live external targets scanned.
