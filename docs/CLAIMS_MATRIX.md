## 2. Forbidden Claims & Strict Terminology Rules

To prevent misleading judges, users, or automated audits, the following claims are **strictly prohibited** across all repository documentation, UI surfaces, and video narrations:

1. **NEVER claim `EXPLOIT_CONFIRMED`:** ChainBreak proves policy-graph reachability (`PATH_VALIDATED`) over modeled edges (`sourceRef`) and hashes (`inputSha256`). It does not execute live exploits against production systems.
2. **NEVER claim live external AI/SaaS execution when keys are unset:** When `TYPESAFE_API_KEY`, `OPENAI_API_KEY`, `CLOUDFLARE_API_TOKEN`, `MANTIS_RUNNER`, or `QUALITY_ENGINE_URL` are unconfigured, outputs and docs must report `NOT_CONFIGURED` / `MOCK` / `PENDING_REVIEW` — never a fabricated remote `PASS`.
3. **NEVER claim `INCONCLUSIVE` is `PASS`:** Under quad-state gate calculus (`ERROR` > `REJECT` > `BLOCK` > `REQUIRES_HUMAN_APPROVAL` > `PASS`), `INCONCLUSIVE` evidence evaluates to `BLOCK` / `REJECT`.
4. **NEVER claim autonomous production merge or deploy:** `mergeAllowed`, `deployAllowed`, `autoApplyAllowed`, `policyMutationAllowed`, `gateMutationAllowed`, and `externalExecution` are locked to `false`.
5. **NEVER claim the public URL or competition repo push is live before human action completes:** Keep public links marked `[Pending Public Deploy — HUMAN_APPROVAL_REQUIRED]` until `PUBLIC_DEMO_URL` and the git push to `https://github.com/andrecodexvictor/scriptkitty-live-hackbrasil-2026` are executed by a human operator.
6. **NEVER leak internal adapter/vendor codenames into top-level hero/product copy:** Product-facing headlines and video captions must present **ScriptKitty Live**, **PatchCat**, **ChainBreak**, **Continuous Security Audit**, **Verified Remediation**, and **Agent & MCP Security**. Internal modules (`@script-kitty/jev-judge`, `@script-kitty/company-context`, `@script-kitty/adapters`, etc.) are documented transparently in technical architecture and provenance files ([`IMPLEMENTATION_PLAN.md`](IMPLEMENTATION_PLAN.md), [`../PROVENANCE.md`](../PROVENANCE.md), [`../NOTICE.md`](../NOTICE.md)).
